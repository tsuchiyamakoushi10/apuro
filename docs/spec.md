### 参照サイトから取った要素

- 角丸の大きいカードと写真、ピル型のボタン
- ブランドカラーをベタで敷いた大きな面（参照サイトの緑 → アプロは青）
- その面の中で、左のテキストを固定したまま右のカードがスクロール連動で動く構造
- 写真に重なる四半円・半円の装飾
- 英字の小見出し＋日本語の大見出し
- 色面は左右に余白を残して角を丸める

### 取らなかった要素

- 自動再生のスライド。スクロール連動に変更した（意図せず動く要素を減らすため）
- 写真の横スクロールマーキー（素材が確保できないため）
- グループ企業バナー

## 2. 未確定項目の管理

`src/config/site.ts` に集約する。未確定値は `【調整中】` の文字列を入れ、画面上は青の点線下線で表示する。

**ビルド時に `【調整中】` を検出したら警告を出すチェックを入れる。** 未確定のまま本番公開されるのを防ぐため。

## 3. デザイントークン

```css
--paper:#FFFFFF;
--mist:#F4F8FA;
--blue:#2A6FA8;
--blue-deep:#1B4E7A;
--blue-ink:#123A5C;
--blue-soft:#DCEAF3;
--sand:#DFC9A5;
--ink:#2B3740;
--ink-muted:#69777F;
--r-lg:40px;
--r-md:28px;
```

**使用ルール**
- `--sand` は採用セクションでのみ使う。他のページに出さない
- 影は使わない
- グラデーションは使わない
- 角丸は `--r-lg` と `--r-md`、ピル型の3種類のみ。カードごとに変えない

**タイポグラフィ**

| 用途 | フォント | 指定 |
|---|---|---|
| 見出し | Zen Kaku Gothic New | 500 / `letter-spacing:.05em` |
| 本文 | Noto Sans JP | 400 / `line-height:1.95` |
| 英字ラベル | Jost | 400 / `letter-spacing:.16em` |
| ヒーローの英字 | Cormorant Garamond | 300 italic |

本文カラムは `max-width:34em`。コンテンツ幅 `1160px`、左右パディング `32px`。

**モーション**

スクロール連動の特徴セクションのみ。自動再生の動きは置かない。`prefers-reduced-motion` に対応する。

## 4. ページ構成

### `/` トップ（5セクション）

1. ヒーロー（メインキャッチ＋サブキャッチ、写真は全幅・下角丸）
2. アプロについて（リード文＋写真＋下層への導線）
3. **特徴**（青ベタ面。左固定＋右カード6枚がスクロール連動）
4. こんなときに、ご相談ください（3対象を各3行で。箇条書きは使わない）
5. 採用バナー
6. お問い合わせ（電話を左、フォームを右）

情報量を絞る方針。詳しい説明は下層に置き、TOPは「何をしている事業所か」と「どこに連絡するか」だけ伝える。

**特徴カードの6項目**

| No | 見出し |
|---|---|
| 01 | 見離さない、見捨てない、諦めない |
| 02 | 精神・介護・医療・看取りのすべてに対応 |
| 03 | 主治医・病院との連携が早い |
| 04 | ご本人だけでなく、ご家族の相談にも応じます |
| 05 | 24時間のオンコール対応 |
| 06 | 在宅で必要な医療処置に幅広く対応 |

各カードは写真＋番号＋見出しのみ。本文は `/service` に置き、カードから遷移させる。

### `/about` アプロについて

1. ミッション（02シート）
2. ビジョン（02シート）
3. バリュー（軸＋5項目）
4. 代表挨拶（`docs/代表挨拶原稿.md`）
5. 会社概要（`site.ts` から生成）

### `/service` 事業紹介

1. サービス概要リード
2. こんなときにご相談ください（TOPより詳細。箇条書きで全項目）
3. 私たちが行うこと（8項目）
4. 対応できる医療処置
5. 受け入れについて（「まずお受けして、そこから考えます」を独立ブロックで）
6. 24時間対応
7. 対応エリア
8. ご利用までの流れ（介護保険／医療保険。**連番を使うのはここだけ**）
9. お問い合わせ

TOPの特徴カード6枚からアンカーリンクで飛べるようにする。

### `/recruit` 採用情報

1. 採用キャッチ＋リード
2. 採用理念
3. 求める人物像（2種類を並列）
4. 働き方の特徴（5項目）
5. 教育・研修（4項目）
6. 福利厚生
7. 正直にお伝えしておきたいこと ← `--sand` を使う唯一のブロック
8. 募集要項（3職種。デスクトップは比較テーブル、モバイルはカード積み）
9. 週4日常勤の訴求文
10. 応募フォームへの導線

選考方法はHPに掲載しない（求人媒体のみ）。

### `/privacy` プライバシーポリシー

Googleフォームで要配慮個人情報を受け取る可能性があるため必須。取得目的、利用範囲、第三者提供、外部サービスの利用、開示請求の窓口を記載。文面は別途作成し、見須様の確認を取る。

## 6. SEO・メタ

- title 例：`アプロ訪問看護ステーション｜国分寺市の訪問看護（精神・介護・医療・看取り）`
- 精神科訪問看護に対応するステーションは地域内で限られるため、`国分寺 訪問看護 精神`、`小金井 精神科訪問看護` を意識した見出し設計にする
- OGP画像はロゴタイプ＋キャッチの組版で作成
- 構造化データ `MedicalBusiness` を実装。住所確定後に投入
- Googleビジネスプロフィールと住所・営業時間・エリアを一致させる

- [ ] Googleフォーム側の「回答をメールで受け取る」がONになっている（初期設定はOFF。設定漏れは応募の取りこぼしに直結する）

## 8. クライアント確認待ちの項目

**公開をブロックするもの**
- 移転後の住所
- 最寄駅と徒歩分数
- 年間休日（祝日を勤務日とするか）
- 給与レンジ
- 訪問エリア（国立市を含めるか）
- キャッチコピーの確定
- Googleフォーム2本のURL
- 代表挨拶の確認

**掲載可否の判断**
- お弁当のエピソード
- 30年間ご自宅から出られなかった方の就労支援（`/service` の特徴02本文にも該当）
- 介護保険事業所番号
- 精神科病院での担当ケースの記述（診断名の組み合わせが具体的なため匿名性の確認）

**あると良い**
- 取得加算の正確なリスト
- ご利用料金の目安
