こころの不調を
抱えている方

気持ちが安定した生活を送りたい。家から出られない。薬を飲み忘れてしまう。眠れない。人との関わりが苦手で困っている。

ご高齢の方・
退院された方

退院後も自宅で医療的な管理が必要。自宅で最期まで過ごしたい。一人暮らしで、体調の変化に気づいてくれる人がいない。

ご家族の方

本人にどう関わればいいか分からない。どこに相談したらいいのか分からない。専門職と本人のやり取りが見えず、不安がある。
